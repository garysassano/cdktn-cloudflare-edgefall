# Diagnostic combat archive format 8

The tank laboratory uses archive **8**, protocol **3.7**, combat snapshot section **2**, and local simulation/recording format **5**. Earlier experimental archives and protocol minors are rejected. Production remains v2; these diagnostic changes do not migrate a deployed room.

The [format 7 contract](combat-checkpoint-v7.md) describes area-attack continuation. This revision adds a tank roster to the private world, 324-byte public vehicle records, and vehicle retirement/spawn lists to checkpoint-continue decisions. The content digest includes the full tank profile and campaign format 2. Checkpoint and journal envelopes retain the existing 512 KiB payload and 1 MiB envelope bounds.

Each private tank retains its public body, action, weapon and ownership fields plus jump buffering, coyote time, turret slew timer, disconnected-tick count, last gun owner and that shot’s input generation. The gun owner remains attached to the last action even if another player later reserves the vehicle. The validator checks the roster, current seat socket and velocity, action cursor, exact eight-way projectile velocity, infinite primary feed, three-armor bound, protection timer and gun attribution. Wrecks stop simulating and retain the destruction boundary; their ownership is always empty.

Input mode changes advance a player’s control epoch once at the accepted world boundary. Reservation, boarding completion, exit initiation, exit completion or cancellation, and forced release all retire the preceding input mode. Multiple causes at one boundary coalesce into one player increment. The vehicle lease generation advances on reservation, release and unowned destruction; `ownerControlEpoch` links the current reserved/occupied player independently of that lease counter.

Prepared journal acknowledgments retain the generation used to evaluate the command. The deterministic step derives seat boundary events and new acknowledgment generations, and journal replay compares the complete accepted result. InputStream commits those generations with all four queues and acknowledgments only after every world outcome validates. Delayed commands keep their original generation and consumed edge cursors; they cannot fire or move a newly controlled entity. Browser capture retains physical held keys but drops unsampled action edges, and prediction neutralizes pending commands from earlier control modes.

A disconnected seated owner has fifteen simulated ticks of neutral control before release. Socket replacement releases immediately before publishing the fresh baseline. Empty pause, expiry and recovery settle seats in the persisted phase boundary because an empty room has no ticking grace timer. Recovery renews run, socket and input generations after settlement. Voluntary exit rejects a blocked path while retaining control; forced release always clears both entities and applies ordinary life loss if no safe candidate exists. A tank crossing the fall boundary resolves its occupant’s death at that boundary.

Continue replenishes one depot tank per player with fresh global entity IDs, alongside fresh enemy IDs. Its retained decision records both retired and spawned vehicle rosters, checks their contiguous allocation and prevents reuse across later continues. It spends exactly one shared credit, renews controller generations and requires the existing loading barrier.

The current tank has an infinite primary gun, short grounded jump and eight authored aim directions. Its cannon, sacrifice action, final art/audio, complete vehicle terrain matrix and production prediction/interpolation remain later work. The [tank evidence](redesign-evidence/W05-tank.md) records the verified scope.

The ordnance increment retains these schemas and changes the content digest to include the lift/press trajectories and grenade inheritance limits. Grenade velocity is bounded to twelve pixels horizontally, twelve and a half upward and eight downward per tick. Existing body support, velocity and bounce fields fully describe continuation: airborne velocity already includes inherited carry, while settled velocity excludes support motion. Proven crush removes the grenade and emits a zero-damage terrain impact; fuse detonation remains a separate terminal outcome. The platform snapshot must match the exact authored trajectory at the retained world tick, and recovery replays the press from that tick. See the [ordnance evidence](redesign-evidence/W05-ordnance.md).
