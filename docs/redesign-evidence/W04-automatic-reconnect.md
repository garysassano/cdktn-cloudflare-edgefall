# W04 automatic room reconnect

The production v2 client and the v3 combat laboratory now share a bounded connection state machine. An interrupted client stops input, reconnects to the same room and accepts its new membership or full baseline before resuming. An expired resume no longer becomes a new join automatically. The v3 browser retains its document and renderer through individual disconnects, a stalled main thread and a fresh workerd process. This is an incremental recovery milestone; production authority still uses v2.

## Connection and admission boundary

Each attempt has a generation checked by open, message, error and close callbacks, asynchronous admission completion and timers. Leaving or changing rooms invalidates the generation before cancelling the old request, closing the socket and suspending gameplay. Synchronous cancellation by a status observer cannot resurrect an attempt. No gameplay is queued across a retry; the production client clears pending prediction and stops input sampling, while the laboratory neutralizes capture and installs a fresh authoritative input mapping and event baseline.

A socket open only enters synchronization. The application validates its own membership or complete snapshot before marking the session connected. Handshakes have a five-second deadline. Equal jitter bounds exponential retry delays between 150 ms initially and less than three seconds at the cap; socket opens and brief flaps do not reset backoff. Five seconds of application readiness starts a new retry budget on the next outage. A continuous outage stops after ninety seconds. Distinct states identify outage, expired reservation, full room, active mission, incompatible build, missing profile, takeover, invalid protocol and room end.

The combat laboratory performs signed admission before each socket attempt. Responses are bounded to 2 KiB and must identify the supported room phase, protocol and exact game identity. Admission failures retain their terminal reason; upstream failures remain retryable. Once its initial browser profile exists, automatic retry never creates another profile. Existing reservation, journaled per-player replacement and baseline-acknowledgment rules remain those proven in the [signed reconnect milestone](./W04-combat-reconnect.md). An intentional same-profile takeover stops the retired tab with no retry timer.

The owned Miniflare harness now retains its service port across process replacement, allowing existing documents to reconnect to the same URL with the same temporary signing key and SQLite directory. Manual verifier scenarios explicitly disable automatic retry so injected failures remain directly observable.

## Preserved clock failures and remaining work

The first manual cohort regression stops after restoring tick 90: its first resumed step rejects `Nonmonotonic server clock`. The independent host samples show wall time dropping by 774 ms and then 1,570 ms while monotonic time advances about 20 ms at each sample. The first event-baseline regression stops at tick 175 on a runtime clock regression from 1788748456440 to 1788748455575; its second attempt stops at tick 159 from 1788748483973 to 1788748483139. Adjacent host samples also move backward in both attempts. All affected rooms stop their timers and input. The passing cohort rerun does not resolve the host-clock cause or close the sustained timing gate. Whole-room recovery remains explicit: clients retry admission while the authority is recovering or paused, but do not automatically restore its state or start a mission. Persisting the last partial journal before an empty pause, expiry alarms and reconnection across every lobby/intermission/terminal mode remain open. In particular, the diagnostic authority does not yet replace an existing loading peer. Production v3 admission, high-entropy room IDs, membership-epoch host commands, atomic membership/result outbox recovery, protected hostile reentry and vehicle ownership are incomplete. The production v2 protocol still has its existing admission limitations; this change improves its transport without claiming the laboratory's v3 contract is deployed.

The browser stall is a bounded main-thread fault and the socket closure is an application-triggered disconnect. Neither proves WAN packet loss, bandwidth impairment, visibility handling, long soaks or deployed latency. Predicted action/effect confirmation, hostile attacks, melee/grenades, tank interaction and the full three-mission campaign remain in progress. W04/G2, W05 and W10 stay open; the W06 human style benchmark still precedes remaining final asset production.
